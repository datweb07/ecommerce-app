## CSP và go-live

Production Next trả CSP Report-Only. Browser test chỉ ghi tên directive, không ghi URL/TLS details, nội dung script hoặc dữ liệu phiên. Trang public ghi nhận `script-src`, `script-src-elem`, `style-src-attr` và `style-src-elem`. Inline script Next/next-themes và inline style cần được xử lý trước khi enforce. Nonce per request đổi đặc tính static rendering, vì vậy phải kiểm lại ISR/cache và Lighthouse nếu chọn hướng đó. Stripe Checkout hiện dùng hosted top-level navigation. Chạy lại cả auth và upload trước khi enforce. Cấu hình HSTS production, `nosniff`, Referrer Policy, Permissions Policy, `X-Frame-Options: DENY`, tắt powered-by và source map. [Next CSP](https://nextjs.org/docs/app/guides/content-security-policy) · [Clerk CSP](https://clerk.com/docs/guides/secure/best-practices/csp-headers) · [Stripe Checkout](https://docs.stripe.com/checkout/fulfillment)

Giai đoạn triển khai cần theo dõi spike 401/403/429, lỗi chữ ký và webhook retry, checkout cần đối soát, MongoDB readiness và lỗi Cloudinary. `/docs` và `/openapi.json` giữ tắt trong API production.

Mẫu cấu hình Dependabot ở `dependabot.phase6.yml`. Đặt mẫu vào `.github/dependabot.yml` khi bật ở Giai đoạn 6.
