# Checklist kiểm thử storefront Giai đoạn 4

Các mục tài khoản và thanh toán bên dưới áp dụng khi từng tính năng từ 4.4 được triển khai. Dùng MongoDB dev và Stripe test mode. Hướng dẫn đặt biến nằm trong [README storefront](../../website/README.md) và [Stripe CLI](stripe-local-testing.md).

| Bước                                                                                                                                    | Kết quả mong đợi                                                                                                                    | Khi khác, kiểm tra                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chạy Docker, seed và `pnpm dev` từ `website/`.                                                                                          | Health ready trả 200. Home, danh mục, chi tiết và sitemap có dữ liệu seed.                                                          | Docker Compose logs, network request catalogue, response request ID.                                                                                             |
| Đăng nhập Google với tài khoản thử của Clerk, từ nút Thêm vào giỏ trên chi tiết.                                                        | Clerk đưa về cùng chi tiết sản phẩm. Một user tương ứng được tạo trong DB web qua webhook hoặc lần đầu API hydrate.                 | Clerk Dashboard sessions/webhook deliveries. DevTools xem status GET /me và request ID. Kiểm tra users theo clerkId bằng Mongo chỉ đọc, tránh chụp PII và token. |
| Thêm sản phẩm và đổi số lượng trong giỏ.                                                                                                | Badge và số lượng cập nhật. Item tồn kho không đủ hiện cảnh báo và chặn checkout.                                                   | Status /cart/items, lỗi 409 và lần GET /cart tiếp theo.                                                                                                          |
| Khởi động `stripe listen --forward-to http://localhost:4000/api/v1/webhooks/stripe`, cấu hình signing secret do CLI cấp và restart API. | CLI nhận event từ account Stripe test, delivery liên quan trả 2xx.                                                                  | CLI, Fastify request ID, Webhook signing secret và account hiện tại.                                                                                             |
| Chọn/thêm địa chỉ ở checkout rồi xem giá quote, bấm thanh toán một lần.                                                                 | Tổng đến từ quote. Hosted Checkout nhận đúng giá và phí. Retry cùng phiên dùng lại Idempotency-Key.                                 | Kiểm tra quote, create session, header key trên DevTools, log theo checkoutId.                                                                                   |
| Dùng thẻ `4242 4242 4242 4242`, ngày tương lai và CVC hợp lệ.                                                                           | Return đọc API từ checkoutId, chuyển pending → paid sau webhook, hiển thị một đơn. Refresh trang return vẫn là cùng đơn.            | Stripe CLI delivery, GET /checkout/sessions/:id và log webhook.                                                                                                  |
| Xem đơn, chuyển sang shipped rồi delivered bằng admin API với expectedStatus.                                                           | Timeline nhận đúng mốc. Inbox nhận thông báo đã giao/đang giao, badge giảm khi đọc.                                                 | Status PATCH admin, request ID, order DTO và /notifications.                                                                                                     |
| Tạo, sửa, xóa đánh giá sao từ đơn đã delivered.                                                                                         | Chỉ chủ đơn có thể thao tác. Điểm sản phẩm công khai được làm mới sau thời gian cache.                                              | /reviews status, GET order canReview, cache catalogue.                                                                                                           |
| Thử thanh toán bằng thẻ từ chối `4000 0000 0000 0002`.                                                                                  | Stripe hiển thị lỗi thẻ và cho phép chọn phương thức khác. Return không báo paid khi API chưa xác nhận.                             | Event timeline test Dashboard, GET checkout session.                                                                                                             |
| Quay lại từ Stripe bằng cancel, rồi refresh return.                                                                                     | Return có cùng query checkoutId như success và dựa vào trạng thái API. Có thể quay lại giỏ hoặc tiếp tục theo trạng thái hiện hành. | URL từ Stripe, API session status, expiresAt, requiresReconciliation.                                                                                            |

Để kiểm tra công khai bằng Edge với API thật và seed, chạy `pnpm --filter @storefront/web smoke:catalogue` trong terminal khác. Ảnh và số đo navigation được lưu hoặc in trong lần chạy.
